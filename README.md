# CADU Games — Prototype

Sala sensorial 3D com o personagem CADU (React + Three.js + Vite).

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra `http://localhost:5173` (mesma Wi‑Fi: use o IP `Network` do terminal).

## Deploy (Vercel)

Projeto publicado em: **https://cadugames.vercel.app/**

Conecte este repositório na [Vercel](https://vercel.com) com:

| Campo | Valor |
|-------|--------|
| Framework | Vite |
| Build | `npm run build` |
| Output | `dist` |
| Root | `.` |

Push na branch `main` dispara deploy automático.
